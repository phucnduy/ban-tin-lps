# Bản tin Chứng khoán LPS

Kho riêng tư. GitHub Actions chạy `update_lps.py` lúc 07:30 và 14:30 (giờ Việt Nam), cập nhật `lps_db.json` và `ban-tin-lps.html`.
Lịch Claude tải `ban-tin-lps.html` về máy cơ quan lúc 08:00 và 15:00.
Chạy tay: tab **Actions** → *Cap nhat Ban tin LPS* → **Run workflow**. Xem hướng dẫn chi tiết trong `HUONG_DAN.txt`.
